# PortAudio's system library (libportaudio2), which Render's default Python
# environment does NOT have preinstalled, so leaving them in would fail the
# build. Both were local-mic-testing leftovers anyway - tata_voice_server.py
# talks over Tata's WebSocket, not a local audio device, so nothing in the
# deployed worker actually needs them. If you ever DO need a local audio
# device on the worker (unlikely), add an apt step (`apt-get install -y
# libportaudio2`) via a Dockerfile and add these two lines back.
